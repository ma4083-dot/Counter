# عداد الوقت — منذ كام

تطبيق ويب (PWA) لحساب الوقت المنقضي من أي تاريخ لحد اللحظة الحالية أو أي وقت تاني، مع إمكانية تثبيت أكتر من تاريخ وتسميته، ويشتغل أونلاين وأوفلاين.

## طريقة الرفع على GitHub Pages

1. اعمل Repository جديد على GitHub (مثلاً باسم `time-counter`).
2. ارفع كل الملفات دي زي ما هي، من غير ما تغيّر أسماءها أو أماكنها:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - مجلد `icons/` (وفيه `icon-192.png` و `icon-512.png`)
3. من إعدادات الريبو: Settings → Pages → Source اختار Branch: `main` والمجلد `/ (root)`.
4. بعد دقيقة أو اتنين، هيديك رابط شبيه بـ:
   `https://username.github.io/time-counter/`
5. افتح الرابط من الموبايل → هيظهرلك زرار "تثبيت التطبيق على الجهاز" (لو المتصفح بيدعم ذلك)، أو من قائمة المتصفح اختار "إضافة إلى الشاشة الرئيسية".

## ملاحظات مهمة

- كل البيانات (التواريخ المثبتة) بتتخزن على جهازك فقط (`localStorage`)، مفيش سيرفر خارجي.
- لو مسحت بيانات المتصفح (Clear browsing data) هتتمسح التواريخ المثبتة.
- التطبيق بيشتغل أوفلاين تلقائيًا بعد أول فتحة أونلاين، بفضل الـ Service Worker (`sw.js`).
- تقدر تفتح `index.html` مباشرة على جهازك للتجربة قبل الرفع، لكن ميزة العمل أوفلاين والتثبيت كتطبيق (PWA) بتحتاج رفعه على رابط https حقيقي زي GitHub Pages.
